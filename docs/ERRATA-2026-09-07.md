# Hostinger release byte-integrity correction

Published: 7 September 2026.

The `hostinger-pages-phishing-2026/v1.0.0` and `v1.1.0` manifests recorded the
Windows CRLF representation of `hostinger-domain-inventory.csv`. Git published
the LF representation under the repository's existing text-normalization rule.
The file's records did not change, but the published byte count and SHA-256 do
not match the historical manifest. This is a release-packaging defect.

| Representation | Bytes | SHA-256 |
| --- | ---: | --- |
| Historical manifest's CRLF copy | 114854 | `388ece72f4f1201a4e763da9d930190543ba0fd16c2f328721f04e28a6ec0ca1` |
| Published LF file | 114550 | `68e49172d4627b92692574d606f1480fadc8062c7fd75b2fa74686fc9c6fd5c4` |

The exact affected LF manifest hashes are:

- v1.0.0: `ce108f1d35294d351ee27d3b1e75530348fe101b43acd8928193a01e121a1472`
- v1.1.0: `a949e1050b35721343f5ab4c0ccd10141a33aa9a1ce3f37be150848904dd7240`

## Correction and archival policy

Use [v1.1.1](../releases/hostinger-pages-phishing-2026/v1.1.1/README.md) for new
downloads and citations of the current package. Its manifest is generated after
normalization and is verified against a clean Git export on Linux and Windows.
This patch changes packaging/correction documentation, not investigative claims
or observation dates. It does not represent renewed observation of the sites.

The historical release directories remain unchanged. Validation recognizes only
this exact case/version/path, both exact historical manifests, the original
declaration and the exact published/original file bytes. It prints an explicit
erratum notice, never a silent generic exemption. Any other bytes or declarations
still fail. Historical consumers should record this erratum alongside the
original version instead of claiming its manifest verified without qualification.

CI also compares released directories with the trusted pre-change commit. A
change to existing release content, including a matching rewrite of its manifest,
is rejected. Future corrections require a new version and visible release notes.
